# Pages

This is where all your HTML pages live.

## Example Usage

Create a new page by adding an HTML file here, e.g. `about.html`, `contact.html`.

Each page should link to the shared CSS and JS files like this:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Page Title</title>
  <link rel="stylesheet" href="../css/styles.css">
</head>
<body>
  <h1>Page Title</h1>
  <script src="../js/main.js"></script>
</body>
</html>
```

> Note: Use `../` to go up one level from `pages/` back to the project root so that the paths to `css/` and `js/` work correctly.
